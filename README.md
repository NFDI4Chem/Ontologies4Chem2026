# Ontologies4Chem2026
This is the repository to organize the [Ontologies4Chem Workshop 2026](https://nfdi4chem.de/event/5th-ontologies4chem-workshop/)

We are looking to identify key topics for the hackathon components of the workshop. All of our current ideas are listed in the [discussions](https://github.com/NFDI4Chem/Ontologies4Chem2026/discussions) section of this repository. 

To help us tailor the workshop to community interest and need, please use the discussions section to add any additional thoughts to our ideas, and to contribute your own ideas for hackathon sessions. Please also make sure to upvote your favourite ideas! We will review these discussions and votes on the 1st September 2026, and use this information to finalise the agenda.

For any new suggested topics, please use the ["ideas" template](https://github.com/NFDI4Chem/Ontologies4Chem2026/discussions/new?category=ideas)

Please note: Whilst we welcome lively discussion, we expect all contributors to be respectful and polite towards others.
